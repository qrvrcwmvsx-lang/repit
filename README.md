# 🫒 Сайт репетитора по математике

Продающий одностраничный сайт: оффер, «знакомо?», подход, обо мне, отзывы, стоимость, шаги, запись на свободное окно, вопросы.
Сайт живёт бесплатно на **GitHub Pages**. Свободные окна вы ставите в **Apple Календаре**, а о каждой записи
вам приходит **приглашение в Календарь** с уведомлением на iPhone.

```
Apple Календарь «Окна» ──(публичная ссылка)──► скрипт Google ◄──► сайт ◄── ученик
                                                    │
                       Google Таблица «Записи» ◄────┤  журнал всех заявок, отмена записи
     приглашение на почту iCloud → Apple Календарь ◄┤  «Урок: Аня (@anna_k)» + уведомление
                             Telegram (по желанию) ◄┘
```

Всё бесплатно: скрипт работает в вашем Google-аккаунте, приглашения рассылает ваш же Google Календарь.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Все тексты сайта: имя, о себе, занятия, цены, вопросы |
| `config.js` | Ссылка на скрипт, часовой пояс, ник в Telegram, отзывы |
| `assets/style.css` | Оформление (цвета — в самом начале файла) |
| `assets/app.js` | Логика записи (трогать не нужно) |
| `google-apps-script/Code.gs` | Скрипт-посредник между Календарём, сайтом и таблицей |

Пока скрипт не подключён, сайт работает в **демо-режиме**: окна выдуманные, заявки никуда не уходят.

## Шаг 1. Календарь «Окна» в Apple Календаре

Отдельный календарь нужен, чтобы на сайт попадали только окна, а не ваши личные дела.

**На iPhone:** Календарь → «Календари» внизу → «Добавить календарь» → назовите **«Окна»** (iCloud) → Готово.
Затем нажмите ⓘ рядом с ним → включите **«Публичный календарь»** → «Поделиться ссылкой» → «Скопировать».

**На Mac:** Файл → Новый календарь → iCloud → **«Окна»**. Правый клик по нему → «Поделиться календарём» →
галочка **«Публичный календарь»** → скопируйте ссылку (начинается с `webcal://`).

> Публичный — значит, по ссылке можно увидеть события этого календаря. В нём будут только окна,
> поэтому называйте их просто «Свободно».

## Шаг 2. Подключаем скрипт

1. Создайте новую Google Таблицу (sheets.new). В **Файл → Настройки** поставьте свой часовой пояс
   (например, «(GMT+03:00) Москва») — время уроков считается по нему.
2. **Расширения → Apps Script**. Удалите то, что там написано, и вставьте содержимое `google-apps-script/Code.gs`.
3. В самом верху скрипта впишите:
   - `CALENDAR_URL` — ссылку на календарь «Окна» из шага 1;
   - `NOTIFY_EMAIL` — вашу почту **iCloud** (на неё придут приглашения).

   Нажмите 💾.
4. Вверху выберите функцию **`setup`** → **Выполнить**. Google попросит доступ к таблице и календарю:
   «Дополнительные настройки → Перейти на страницу проекта» → Разрешить. Это ваш собственный скрипт.
5. **Начать развертывание → Новое развертывание → тип «Веб-приложение»**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**

   Скопируйте ссылку вида `https://script.google.com/macros/s/…/exec`.
6. Вставьте её в `config.js` → `API_URL: '…'` (или пришлите Claude — он вставит и обновит сайт).
7. Проверьте в таблице: **🫒 Расписание → Показать свободные окна** и **Отправить тестовое приглашение**.

> Если потом меняете код в Apps Script — **Начать развертывание → Управление развертываниями → ✏️ →
> Версия: новая → Развернуть**. Тогда ссылка останется прежней.

## Шаг 3 (по желанию). Мгновенные уведомления в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Напишите своему новому боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой **chat id** у [@userinfobot](https://t.me/userinfobot).
4. Впишите их в начале скрипта (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) и обновите развертывание.

## Как этим пользоваться каждый день

**Добавить окна** — создайте событие в календаре «Окна».
- Событие **15:00–19:00** превратится на сайте в 4 урока по часу (длина урока — `SLOT_MINUTES` в скрипте).
- Можно делать **повторяющиеся** события: «каждый вторник 17:00–20:00». Исключить один день — удалите только этот повтор.
- События «на весь день» сайт не учитывает.

**Убрать окно** — удалите или сократите событие.

**Кто-то записался** — на iPhone придёт уведомление о приглашении «Урок: Аня (@anna_k)» (Календарь → «Входящие»).
Нажмите «Принять» — урок встанет в ваш календарь, и перед ним будет обычное напоминание.
Окно сразу пропадает с сайта, а заявка появляется в таблице «Записи».

**Ученик отменил** — в таблице «Записи» поставьте статус **«отменена»**: окно снова появится на сайте.
Сам урок удалите из Календаря.

**Важно про задержку:** Apple обновляет публичный календарь не мгновенно. Новое окно может появиться на сайте
через несколько минут (иногда дольше). А вот занятое окно пропадает с сайта сразу.

Сайт показывает окна от «через 3 часа» до «через 30 дней» — это меняется в начале скрипта
(`MIN_HOURS_BEFORE`, `DAYS_AHEAD`).

> Если приглашения приходят письмом, а не в Календарь: на icloud.com → Календарь → ⚙️ Настройки →
> «Получать приглашения как» → «Уведомления в приложении».

## Как менять тексты, фото и цены

- Тексты — прямо в `index.html` (на GitHub: открыть файл → ✏️). Всё, что на сайте, там написано обычным текстом.
- Фото — загрузите `assets/photo.jpg` и в `index.html` замените блок `<svg class="sheet">…</svg>`
  на `<img src="assets/photo.jpg" alt="Ваше имя">` (рядом есть подсказка в комментарии).
- Цвета — в начале `assets/style.css`, раздел «Палитра».
- Отзывы — в `config.js`, список `REVIEWS` (там есть образец). Пока он пустой, блок «Отзывы» скрыт.
  Публикуйте только настоящие отзывы и с разрешения автора.

## Защита от двойной записи и спама

- Если двое одновременно выбирают одно окно, запишется только первый; второму сайт предложит выбрать другое время.
- Скрытое поле-ловушка отсекает простых спам-ботов.
- Ссылка на скрипт видна в коде сайта. Через неё можно только посмотреть свободные окна и оставить заявку;
  таблицу и ваш основной календарь видите только вы.
