# 🫒 Сайт репетитора по математике

Продающий одностраничный сайт: оффер, «знакомо?», подход, обо мне, отзывы, стоимость, шаги, запись на свободное окно, вопросы.
Живёт бесплатно на **GitHub Pages**, расписание и заявки — в обычной **Google Таблице**.

```
Ученик ──► сайт на GitHub Pages ──► Google Apps Script ──► Google Таблица
                                              │                 ├─ лист «Окна»   ← вы редактируете
                                              │                 └─ лист «Записи» ← заявки падают сами
                                              └──► Telegram-бот пишет вам «Новая запись!»
```

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Все тексты сайта: имя, о себе, занятия, цены |
| `config.js` | Ссылка на таблицу, часовой пояс, ник в Telegram, отзывы |
| `assets/style.css` | Оформление (цвета — в самом начале файла) |
| `assets/app.js` | Логика записи (трогать не нужно) |
| `google-apps-script/Code.gs` | Код, который вставляется в Google Таблицу |

## Шаг 1. Выкладываем сайт на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) и нажмите **New repository**.
   Назовите, например, `tutor`. Видимость — **Public**.
2. На странице репозитория: **Add file → Upload files**, перетащите все файлы и папки
   (кроме `google-apps-script` — её можно не загружать) и нажмите **Commit changes**.
3. **Settings → Pages → Branch: `main`, папка `/ (root)` → Save**.
4. Через минуту сайт откроется по адресу `https://ВАШ-НИК.github.io/tutor/`.

Пока таблица не подключена, сайт работает в **демо-режиме**: окна выдуманные, заявки никуда не уходят.

## Шаг 2. Подключаем таблицу

1. Создайте новую Google Таблицу (sheets.new). В **Файл → Настройки** поставьте
   регион «Россия» и нужный часовой пояс — время в таблице считается по нему.
2. **Расширения → Apps Script**. Удалите то, что там написано, вставьте содержимое
   `google-apps-script/Code.gs`, нажмите 💾.
3. Вверху выберите функцию **`setup`** → **Выполнить**. Google попросит доступ к таблице:
   «Дополнительные настройки → Перейти на страницу проекта» → Разрешить. Это ваш собственный скрипт.
   Появятся листы «Окна» (уже с примером) и «Записи».
4. **Начать развертывание → Новое развертывание → тип «Веб-приложение»**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   Нажмите «Начать развертывание» и скопируйте ссылку вида `https://script.google.com/macros/s/…/exec`.
5. На GitHub откройте `config.js` → ✏️ → вставьте ссылку в `API_URL: '…'` → Commit.

Готово: на сайте теперь ваши настоящие окна.

> Если потом поменяете код в Apps Script — **Начать развертывание → Управление развертываниями → ✏️ →
> Версия: новая → Развернуть**. Тогда ссылка останется прежней.

## Шаг 3 (по желанию). Уведомления в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Напишите своему новому боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой **chat id** у [@userinfobot](https://t.me/userinfobot).
4. В Apps Script впишите их в самом верху: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, сохраните
   и обновите развертывание (см. выше).
5. В таблице: **🫒 Расписание → Проверить уведомление в Telegram**.

## Как редактировать окна

Всё делается в листе **«Окна»**, сайт подхватывает изменения сразу:

| Дата | Время | Длительность, мин | Статус | Кто записан |
|---|---|---|---|---|
| 14.10.2026 | 18:00 | 60 | свободно | |
| 14.10.2026 | 19:30 | 60 | занято | Аня · @anna_k |

- **Добавить окно** — новая строка с датой и временем (статус можно оставить пустым).
- **Убрать окно** — удалите строку или поставьте «занято».
- **Освободить окно** (ученик отменил) — выберите «свободно».
- Меню **🫒 Расписание → Повторить последнюю неделю** копирует окна на неделю вперёд.
- **🫒 Расписание → Убрать прошедшие окна** чистит старые строки (заявки в «Записях» остаются).

На сайте показываются только свободные окна от «через 3 часа» до «через 30 дней» —
это меняется в начале `Code.gs` (`MIN_HOURS_BEFORE`, `DAYS_AHEAD`).

## Как менять тексты, фото и цены

- Тексты — прямо в `index.html` (на GitHub: открыть файл → ✏️). Всё, что на сайте, там написано обычным текстом.
- Фото — загрузите `assets/photo.jpg` и в `index.html` замените блок `<svg class="branch">…</svg>`
  на `<img src="assets/photo.jpg" alt="Ваше имя">` (рядом есть подсказка в комментарии).
- Цвета — в начале `assets/style.css`, раздел «Палитра».
- Отзывы — в `config.js`, список `REVIEWS` (там есть образец). Пока он пустой, блок «Отзывы» скрыт.
  Публикуйте только настоящие отзывы и с разрешения автора.

## Защита от двойной записи и спама

- Если двое одновременно выбирают одно окно, запишется только первый; второму сайт предложит выбрать другое время.
- Скрытое поле-ловушка отсекает простых спам-ботов.
- Ссылка на скрипт видна в коде сайта. Через неё можно только посмотреть свободные окна и оставить заявку, а саму таблицу видите только вы.
